# ADR 0001 — Способ развёртывания приложения

## Решение

Для обновления приложения TimeCapsule используется ручной способ.

## Как происходит обновление

1. Изменения отправляются в GitHub.
2. На сервере EC2 загружаются новые файлы.
3. Проверяется работа приложения.

## Почему выбран этот способ

Ручное обновление проще настроить для учебного проекта. В дальнейшем процесс можно автоматизировать.
